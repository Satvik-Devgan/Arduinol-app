# LostGuard

Web app for the LostGuard Bluetooth belongings tracker (Arduino + HC-05).

- `index.html`: the app. Open it in Chrome on Android, or Chrome or Edge on a computer.
- `arduino/LostGuard/LostGuard.ino`: tracker firmware that understands the app's commands.

Pair the HC-05 in Bluetooth settings first (PIN 1234 or 0000), then tap Connect.
